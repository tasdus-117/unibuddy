# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/49667dc7-636f-498c-9617-35cf772e1823

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in a `.env` file next to `server.ts`. Use [.env.example](.env.example) as a reference.
3. Run the app:
   `npm run dev`
